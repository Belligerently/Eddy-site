Features

What the current build of Eddy does, what is planned, and where it has been tested. Version {{version}}, built and tested locally, not released.

In the current build {{icon:check}}Implemented

Catalog worth, filters and sorting

Limited items on Vortex's catalog get a Worth line from Voltimons' unofficial market data, with value presets, a min–max range and sorting. Filters apply to the cards already on the page. Only while Market data is on.

Avatar Value on profiles

The combined worth of the limited items a profile lists as worn. Items without a worth make it read “≥ …, incomplete”. Only while Market data is on.

Inventory section on profiles

Shows every total as “Unavailable” and explains why: Vortex inventories are not public.

Toolbar popup

Search, value presets, “only items with an estimate” and sorting over a labelled sample dataset. Demo data is off by default.

Settings, in the extension and inside Vortex

Theme, demo data, market data, display toggles and reset, on Eddy's own settings page and in an Eddy tab inside Vortex's Settings. Eddy also adds an “Eddy settings” entry to Vortex's account menu. Market data can be turned on only on Eddy's own settings page; inside Vortex it can only be turned off.

Estimated-value dataset format

A versioned dataset format with a strict validator, ready for a reviewed community dataset.

Planned {{icon:clock}}Not in this version

Public release

Blocked on three open conditions: confirmed authorisation from Vortex, Voltimons' permission to reuse and display its data, and access to Voltimons' API. More on the release

Real RAP from completed sales

Needs an approved source of completed sales. Until then Eddy shows no RAP of its own.

Inventory totals

Vortex inventories are not public, so inventory statistics cannot work yet.

Community estimated values

Estimates from a reviewed community dataset, in the format above.
